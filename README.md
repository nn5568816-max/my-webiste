# NARESH EXPLOITS — Vercel-ready portfolio

## Deploy
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework Preset: **Other** (or leave it detected as a static site).
4. Build Command: leave empty.
5. Output Directory: leave empty.
6. Deploy.

## Optional files
- Put `hacker.jpg` in this same folder if you want the profile photo.
- Put `app.apk` here and set `SITE_CONFIG.appUrl` in `index.html` to `/app.apk`, or use a hosted APK URL.

## Customize
In `index.html`, edit:
- `SITE_CONFIG.whatsappNumber`
- `SITE_CONFIG.customLink`
- `SITE_CONFIG.appUrl`
